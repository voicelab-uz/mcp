name: voicelab-team-agents
description: Plan and delegate a substantial coding task across available agents when independent work can run in parallel without avoidable overhead.
---

Read and follow [the team workflow reference](references/team-agents.md).

Use for task decomposition and coordination. Keep trivial or tightly coupled
work with one agent. The current lead owns the plan, design decisions,
integration, and final diff review; subagents take explicit bounded slices.
